# 🔌 Home Energy Management API
The backend application manages the user's electricity consumption, built with **Golang (Gin Framework)**.
The project provides APIs that allow user management, record daily electricity consumption, calculate electricity bills according to EVN price list, and create comparison reports over time.

---

## ⚙️ Technology used

- **Language:** Go 1.22+
- **Framework:** Gin
- **ORM:** GORM
- **Database:** MySQL
- **Authentication:** JWT
- **Containerization:** Docker
